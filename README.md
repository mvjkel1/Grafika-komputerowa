# Temat projektu:
Rysowanie lens-flares przy patrzeniu w źródło światła. Wykrywanie czy jest widoczne + płynne ich zanikanie".

Projekt został zrealizowany z wykorzystaniem biblioteki języka JavaScript o nazwie ThreeJs.

Aby usprawnić proces sprawdzania pracy, postanowiliśmy użyć gotowego środowiska do wyświetlania rezultatów naszego projektu:

https://codesandbox.io/s/confident-elbakyan-98gfcc?file=/index.js

Być może trzeba będzie kilka razy odświeżyć stronę, aby projekt w pełni się załadował.

Natomiast gdyby chciałby Pan faktycznie pobrać projekt i go uruchomić, należy:

1. Sklonować projekt na dysk
- git clone https://github.com/mvjkel1/Grafika-komputerowa.git

2. Pobrać środowisko uruchomieniowe języka JavaScript:
- https://nodejs.org/en/

3. Zainstalować wymagane paczki uwzględnione w pliku package.json:
- npm install

4. Uruchomić projekt:
- npm start

W razie problemów z uruchomieniem proszę o kontakt mailowy.
